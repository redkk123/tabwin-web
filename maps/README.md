# Bundled TabWin maps

These two legacy cartographic assets were supplied by the project owner in an
authorized TabWin 4.15 distribution on 2026-08-26. They are included so a DBC
grouped by municipality or UF can produce a map without another download.

| File | Purpose | SHA-256 |
| --- | --- | --- |
| `br_municip.MAP` | 5,570 Brazilian municipalities | `BB8D09EA2B47CF422F8ADD4C49C16AB8D5EEA0487CC1E76FC398B7E7140011FA` |
| `br_ufsigla.MAP` | 27 Brazilian federative units, abbreviated names | `D97DA34FD7831B0577A37135C6875F9BE5968281AA7D1F57E552A3ADDE92AD56` |

The application parses the binary assets locally. It never transmits a user's
microdata to associate a result with these geometries.
