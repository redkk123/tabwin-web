# R04.0 — G001 exact TabWin 4.15 golden equivalence

**Date:** 2026-08-27  
**Status:** PASS — EXACT STRUCTURAL AND NUMERIC EQUALITY, TOLERANCE ZERO

## 1. Outcome

G001 is the project's first real end-to-end compatibility proof against the
original Windows TabWin 4.15 oracle. The same public SIH-RD DBC, official DEF,
official CNV and analysis recipe produced equal row labels, row order, column
label, shape and every numeric cell.

This milestone proves only the covered slice: ordinary frequency by one
legacy-CNV-backed row dimension with no column, filters or zero-row suppression.
It does not justify a blanket compatibility claim for unrelated TabWin behavior.

## 5. Defects exposed by the oracle

The first strict run correctly failed before comparison on two real differences:

1. Current `RD2008.DEF` lines 389 onward contain six-field lookup directives.
   The parser previously rejected any option with more than four fields. It now
   preserves unresolved trailing fields and emits an audit warning; it does not
   invent execution semantics for them.
2. The single count column used the generic Web label `Valor`. The original
   export uses `Freqüência`. The executor now derives the exact legacy label
   only under `compatibilityProfile: tabwin-4.15`.

Neither reference values nor row order were changed to make the test pass.
